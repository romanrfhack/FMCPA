# FAQ para donantes - Donatarias Transparencia

## ¿Cómo sé cuánto se recibió?

En el resumen de la donación y en el reporte de transparencia se muestra el total recibido. Para el escenario demo, el total recibido es `100000`.

## ¿Cómo sé cuánto se aplicó?

El sistema suma las aplicaciones registradas contra la donación seleccionada. En el escenario demo hay tres aplicaciones por `35000`, `30000` y `20000`, con total aplicado de `85000`.

## ¿Dónde veo el saldo pendiente?

El saldo pendiente aparece en los KPIs de la donación y en el reporte de transparencia. En el escenario demo el saldo pendiente es `15000`, por eso el readiness final es `PARTIAL`.

## ¿Cómo se comprueba cada aplicación?

Cada aplicación puede tener evidencia registrada desde su contexto. La evidencia queda asociada a la aplicación correspondiente y puede consultarse o descargarse cuando existe.

## ¿Qué pasa si falta evidencia?

El sistema lo muestra como faltante documental. En la demo, una aplicación inicia sin evidencia para enseñar cómo se detecta el faltante y cómo se remedia cargando un PDF válido de prueba desde el modal contextual.

## ¿La evidencia es legalmente suficiente?

No debe presentarse así. La evidencia mínima registrada acredita que existe un documento asociado en el sistema, pero no sustituye revisión legal, fiscal, contable ni validación documental formal.

## ¿Puedo recibir un PDF oficial?

La versión actual no debe ofrecerse como PDF oficial. La pantalla incluye una vista imprimible operativa que sirve para revisión visual, pero no genera folio, firma, snapshot persistido ni versión oficial del reporte.

## ¿Puedo consultar el reporte después?

Sí, un usuario autorizado puede consultar el reporte desde el tab `Reporte de transparencia` dentro de `/donatarias`. El reporte usa los datos actuales registrados en el sistema.

## ¿Quién puede cerrar una donación?

El cierre formal requiere permiso administrativo. Para la demo se recomienda no confirmar el cierre, especialmente si existe saldo pendiente o si el objetivo es mostrar advertencias de control.

## ¿Qué sigue si queremos reporte formal?

El siguiente paso es definir el alcance institucional del reporte formal: formato, responsables de revisión, criterios legales/fiscales/contables, folio, firma, versionamiento, snapshot de datos y proceso de autorización.

## ¿El readiness `PARTIAL` es negativo?

No necesariamente. `PARTIAL` indica que existe información útil para presentar, pero quedan pendientes financieros o documentales. En este escenario el pendiente es financiero: quedan `15000` sin aplicar.

## ¿El sistema reemplaza la revisión interna?

No. El módulo ordena la información y permite revisar el avance operativo. La revisión institucional, legal, fiscal, contable o documental especializada sigue dependiendo de los responsables definidos por FMCPA.
