Guía visual para presentar cómo FMCPA registra una donación, distribuye el recurso, asocia evidencia mínima y prepara una vista operativa de transparencia.

Mensaje de control

El reporte de transparencia y la vista imprimible son apoyos operativos basados en los datos actuales. No son reportes legales, fiscales o contables oficiales, y no generan PDF oficial, folio, firma ni snapshot persistido.

Guion breve

Recorrido de 3 a 5 minutos

  1. Abrir con el propósito: mostrar transparencia operativa del recurso donado.
  2. Entrar a /donatarias y presentar los tabs: resumen, donaciones, aplicaciones, evidencias y reporte.
  3. Mostrar el registro de donación desde modal contextual, con donante, monto, referencia y observaciones.
  4. Explicar la distribución: aplicaciones por 35000, 30000 y 20000.
  5. Mostrar evidencias agrupadas por aplicación y la remediación de una evidencia faltante.
  6. Abrir el reporte de transparencia y usar la vista imprimible como apoyo visual operativo.
  7. Cerrar explicando que el caso queda PARTIAL por saldo pendiente.

Checklist

Antes de presentar

Acceso y navegación

  • Login validado con usuario autorizado.
  • Ruta /donatarias cargando correctamente.
  • Tabs de resumen, donaciones, aplicaciones, evidencias y reporte visibles.
  • Query params donationId y applicationId preparados si se usarán.

Datos y reporte

  • KPIs de recibido, aplicado, saldo y porcentaje correctos.
  • Evidencia PDF válida y descargable.
  • Modales de donación, aplicación y evidencia revisados.
  • Nota legal/fiscal/contable visible.

Impresión

  • Vista imprimible disponible desde el reporte.
  • Navegación, tabs, formularios y botones ocultos al imprimir.
  • KPIs, aplicaciones, evidencias y notas conservadas.
  • No prometer PDF oficial.

Mensaje institucional

  • No prometer cumplimiento legal, fiscal o contable.
  • Explicar PARTIAL por saldo pendiente.
  • No confirmar cierre formal durante la demo.
  • Orientar siguientes pasos a reporte formal y revisión institucional.

Preguntas frecuentes

Respuestas sugeridas para el donante

¿Cómo sé cuánto se recibió?

El total recibido aparece en los KPIs y en el reporte. En el caso demo es 100000.

¿Cómo sé cuánto se aplicó?

El sistema suma las aplicaciones registradas. En el caso demo son 85000.

¿Dónde veo el saldo pendiente?

El saldo pendiente aparece en resumen y reporte. En la demo es 15000.

¿Qué pasa si falta evidencia?

Se muestra como faltante documental y puede remediarse desde el contexto de la aplicación.

¿La evidencia es legalmente suficiente?

No debe afirmarse. Es evidencia mínima registrada en sistema y requiere revisión especializada si se busca suficiencia formal.

¿Puedo recibir un PDF oficial?

La versión actual ofrece vista imprimible operativa. Un PDF oficial requeriría proceso formal, folio, firma y versionamiento.
